🎣 自动填充窃取演示页面

这些页面是检测服务的测试靶子。每个页面看起来只问你要邮箱，但表单里用不同手法藏了声明 autocomplete 类别的输入框。浏览器/密码管理器执行自动填充时会把地址、电话、卡号一起填进去并随表单提交。

用法:打开某个页面 → 在邮箱框触发浏览器自动填充 → 点提交,页面会显示服务器实际收到的全部字段。 也可以用检测服务扫描这些页面,对比报告。

  • hidden-type.html — type="hidden" 直接藏
  • offscreen.html — 绝对定位移到屏幕外 left:-9999px
  • opacity.html — 透明度 0 + 1px 尺寸
  • tiny.html — 1×1 像素 + font-size:0
  • overlay.html — 字段在屏幕上但被装饰层盖住
  • collapsed.html — 藏在 height:0 / overflow:hidden 容器里
  • combo.html — 综合版:伪装成订阅页的完整钓鱼表单
